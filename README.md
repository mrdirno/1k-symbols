# 1k Symbols

An open reference of one thousand symbols — names, meanings, and marks.
Free forever. Part of the [Persona500](https://persona500.com/) network.

## Use it
Open `index.html` in any browser. No build step, no server, no tracking.
Host it anywhere static (GitHub Pages, Netlify, a folder on your site).

## Improve it ("Wish it better")
Something wrong — a meaning, a missing symbol, the vibe? File a wish on
[persona500.com](https://persona500.com/) (the "✦ Wish it better" card on the
page takes you there). Every wish feeds the next version; corrections sourced
from the symbols' home cultures ship first.

Or fork it: the page is a single self-contained file — edit, improve, send it
back into the world under the same MIT license.

## Product line
This repo is the v1.0 release of the Symbols product line (Persona500 LLC).
The line runs a cyclical evo loop: wishes → triage → gated release, every
cycle versioned in `CHANGELOG.md`. Pipeline docs live alongside the page
(`PRODUCT.md`, `EVO.md`, `HYPERPARAMETERS.md`).
